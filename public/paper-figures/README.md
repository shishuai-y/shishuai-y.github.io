# Publication figures

These WebP previews are rendered crops of the corresponding, unchanged PDFs in
`../papers/`. The source page, figure number, description, and crop coordinates
(PDF points, top-left origin) are recorded in `sources.json`.

Each image shows the original framework, measurement flow, or analysis workflow.
Images are rendered at three pixels per PDF point and displayed without cropping
on the homepage. No diagram content has been redrawn or generated.

Copyright and reuse terms remain with the original authors and publishers.
The website's MIT license does not license these figures. See `../papers/README.md`
for the source and licensing information for each paper.
